# DREDGE — 모작 프로젝트

《DREDGE》를 C++ / DirectX 11로 구현한 개인 프로젝트입니다.

선박으로 바다를 탐험하며 물고기를 잡고, 마을에서 판매·장비 구매·수리·창고 보관으로 이어지는 플레이 흐름을 구현했습니다. 해상 환경 렌더링과 비정형 인벤토리, 이를 지원하는 엔진·UI 구조를 제작하는 데 중점을 두었습니다.

## 주요 구현

### 해상 렌더링과 선박 부유

- Gerstner Wave를 합성한 해수면과 링 형태의 LOD 메시 구성
- 높이맵 기반 해안 표현, 해수면 조명·프레넬 효과 적용
- 불투명 오브젝트는 디퍼드, 해수면·투명 오브젝트는 포워드 방식으로 렌더링
- 해수면 높이를 샘플링해 선박의 높이와 기울기 갱신

### 비정형 인벤토리

- 아이템의 실제 점유 형태와 회전을 고려한 배치·교환 판정
- 경계·잠금·파손·장비 슬롯 조건 검사와 배치 결과 표시
- 플레이어·창고·상점 사이의 아이템 이동과 공통 인벤토리 로직
- 장비 효과 합산과 낚시 가능 해역 플래그를 통한 선박 능력치 갱신

### 자체 UI 프레임워크

- UI 계층·좌표 변환·입력 우선순위·레이어 관리
- 공통 인터페이스를 통한 페이드·이동·회전·크기 변화 연출
- 아이템과 조작 상황에 따라 내용·크기가 변하는 툴팁
- JSON 노드·선택지 기반 분기 대화와 카메라·상태 UI 연결

### 선박 제어와 게임플레이

- 가속·감속을 적용한 선박 이동과 회전·자동 복귀를 지원하는 추적 카메라
- 어장별 물고기 설정과 두 종류의 타이밍 판정 낚시 미니게임
- 충돌 레이어·마스크 기반 대상 필터링과 피격에 따른 체력·인벤토리 손상

### 엔진 구조와 제작 도구

- 컴포넌트·프로토타입 기반 객체 생성과 공통 리소스 공유
- 모델 바이너리 변환, 키프레임 보간과 GPU 스키닝
- EventBus 기반 시스템 간 이벤트 전달과 클래스 기반 FSM
- ImGui 기반 오브젝트·UI·환경 편집, CPU·GPU 구간별 처리 시간 표시
- 맵 객체·컴포넌트와 UI 배치·속성의 JSON 저장·복원

## 주요 설계

### 해수면과 선박의 파도 계산 공유

셰이더의 해수면 변형과 CPU의 선박 부유에 같은 파도 계산식을 사용했습니다. 선박 중심과 주변 지점의 높이를 샘플링해 위치와 기울기를 구하고, 보간을 적용해 파도에 따라 움직이도록 구성했습니다.

### 점유 좌표 기반 배치와 데이터 분리

아이템의 점유 마스크에서 네 방향의 점유 좌표를 미리 계산하고, 실제 점유 칸만 검사해 비정형 아이템의 배치와 교환을 판정했습니다. 공통 정의와 개별 아이템 상태를 분리하고, 들고 있는 아이템을 인벤토리 밖에서 관리해 서로 다른 창에서도 같은 배치 로직을 사용했습니다.

### 공통 리소스 공유와 개별 상태 분리

객체와 컴포넌트의 원형을 등록하고 복제해 인스턴스를 생성했습니다. 모델의 메시·머티리얼은 공유하고, 애니메이션·본은 개별 복제해 객체별 재생 상태를 독립적으로 관리했습니다.

### 이벤트와 상태별 처리 분리

플레이어·인벤토리의 변경 정보를 EventBus로 전달해 관련 UI·카메라가 구독하도록 구성했습니다. 항해·낚시·마을·상점의 입력과 행동은 상태별 클래스로 분리하고, `Exit()`·`Enter()`에서 종료·진입 처리를 관리했습니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `Engine` | 렌더링·오브젝트·컴포넌트·충돌 등 공통 엔진 |
| `Client` | 게임플레이·UI·아이템·상태별 로직 |
| `EditorTool` | ImGui 기반 제작·디버깅 도구 |
| `Assimp_Converter` | 모델 리소스 바이너리 변환 도구 |
| `EngineSDK` | 클라이언트에서 사용하는 엔진 헤더·라이브러리 |

## 빌드 및 실행 안내

Visual Studio 2022의 C++ 개발 환경(v143)과 Windows SDK가 필요합니다. 외부 라이브러리와 실행 리소스도 프로젝트의 참조 경로에 맞게 준비해야 합니다.

- `3D_DX11.sln`을 열고, 외부 라이브러리의 헤더·라이브러리 경로를 확인합니다.
- `Client`를 시작 프로젝트로 지정하고 빌드합니다.
- 실행 시 작업 디렉터리를 `Client/Bin`으로 설정하고, 필요한 DLL과 `Resources`·`ShaderFiles`가 해당 경로에 있는지 확인합니다.

위 내용은 프로젝트 설정 기준의 안내이며, 별도 환경에서의 클린 빌드·실행은 검증하지 않았습니다.
