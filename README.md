# DREDGE — 모작 프로젝트

《DREDGE》를 C++ / DirectX 11로 구현한 개인 프로젝트입니다.

선박으로 바다를 탐험하며 물고기를 잡고, 마을에서 판매·장비 구매·수리·창고 보관으로 이어지는 플레이 흐름을 구현했습니다. 해상 환경 렌더링과 비정형 인벤토리, 이를 지원하는 엔진·UI 구조를 제작하는 데 중점을 두었습니다.

## 주요 구현

### 해상 환경과 렌더링

- Gerstner Wave 기반 파도와 링 형태의 해수면 LOD
- 높이맵을 활용한 해안 표현과 해수면 조명·프레넬 효과
- 디퍼드·포워드 렌더링을 함께 사용하는 렌더링 파이프라인
- 시간대별 하늘·구름, 깊이·높이 기반 안개, 높이·경사에 따른 지형 색상

### 선박 제어와 게임플레이

- 가속·감속을 적용한 선박 이동과 해수면 샘플링 기반 부유
- 선박 추적 카메라와 대화·상점 진입 시 카메라 전환
- 회전 바늘·확장 링 방식의 낚시 미니게임과 일반·변종 물고기 획득
- 레이어 기반 충돌 검사와 선박 피해·무적 시간·슬롯 파손 처리

### 아이템과 UI 시스템

- 실제 점유 칸과 회전을 고려한 비정형 인벤토리 및 창 사이 아이템 이동
- UI 계층·입력 우선순위·레이어 관리와 페이드·이동·회전·크기 변화 연출
- 아이템·조작 상태에 따라 내용과 크기가 변하는 툴팁
- JSON 노드·선택지 기반 분기 대화와 카메라·상태 UI 연결

### 엔진 구조와 제작 도구

- 컴포넌트·프로토타입 기반 오브젝트 생성과 리소스 공유
- 모델 바이너리 변환과 키프레임 보간·스키닝
- ImGui 기반 오브젝트·컴포넌트·환경 설정 편집
- 맵·UI 설정의 JSON 저장 및 불러오기

## 주요 설계

### 인벤토리 로직 공통화

인벤토리를 컴포넌트로 제작해 플레이어·창고·상점의 보관·배치·교환 로직을 공통화했습니다. 들고 있는 아이템은 별도로 관리하고, 마우스가 위치한 창을 대상으로 배치를 판정해 인벤토리 간 이동을 처리했습니다.

### 아이템 정의와 개별 상태 분리

공통 정보는 `Item_Def`, 회전·신선도·크기 등 개별 상태는 `Item_Inst`로 분리했습니다. 정의는 벡터에 저장하고 ID별 인덱스를 `unordered_map`에 등록해 평균 O(1)로 조회하며, 상수 참조로 반환하도록 구성했습니다.

### FSM을 통한 게임 상태 관리

항해·낚시·마을·상점의 입력과 행동을 상태별 클래스로 분리했습니다. 상태 전환 시 `Exit()`와 `Enter()`에서 UI·카메라 등의 종료·진입 처리를 관리해, 상태 추가와 기능 수정이 용이하도록 구성했습니다.

## 프로젝트 구조

| 경로 | 역할 |

| `Engine` | 렌더링·오브젝트·컴포넌트·충돌 등 공통 엔진 |

## 빌드 및 실행 안내

Visual Studio 2022의 C++ 개발 환경(v143)과 Windows SDK가 필요합니다. 외부 라이브러리와 실행 리소스도 프로젝트의 참조 경로에 맞게 준비해야 합니다.

- `3D_DX11.sln`을 열고, 외부 라이브러리의 헤더·라이브러리 경로를 확인합니다.
- `Client`를 시작 프로젝트로 지정하고 빌드합니다.
- 실행 시 작업 디렉터리를 `Client/Bin`으로 설정하고, 필요한 DLL과 `Resources`·`ShaderFiles`가 해당 경로에 있는지 확인합니다.

위 내용은 프로젝트 설정 기준의 안내이며, 별도 환경에서의 클린 빌드·실행은 검증하지 않았습니다.
